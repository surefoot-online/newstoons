# NewsToons 📺

**Today's news, tomorrow's adventure.** The day's news, redrawn as a friendly six-panel comic for kids of all ages — starring Priya, Miles, and Sprocket the robot.

**Read the episodes: https://surefoot-online.github.io/newstoons/**

Every episode retells real news stories at a grades 2–3 reading level: hard stories are told through helpers and community response, wonder gets center stage, and the facts stay true to the source reporting.

## How it's made

Episodes are produced by the Family M-Team's agent studio (humans + AI working together) and published here. This repo holds only the generated site; the studio, masters, and pipeline live in a private repository.
